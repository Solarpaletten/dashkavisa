## 1) D=>C | CLOUD ТЗ (полное)

**Цель:** провести полный аудит репозитория Dashkavisa, добиться чистого запуска/теста, описать все блокеры и причины.

### Обязательные действия Claude

1. **Снять карту проекта**

   * `tree -a -I "venv|__pycache__|.git" > docs/AUDIT_TREE.txt`
   * определить entrypoints: `main.py`, `run.sh`, `run_registration.py`, `automation/*`
   * определить конфиги: `config.py`, `.env*`, `requirements.txt`

2. **Проверить окружение**

   * Python version, pip, venv
   * зависимости `requirements.txt` ставятся без ошибок

3. **Запуск в 3 режимах**

   * `python main.py` (если есть)
   * `python automation/browser.py`
   * `python run_registration.py` (или текущий сценарий регистрации)

4. **Тестирование**

   * если есть pytest: `pytest -q`
   * если тестов нет: создать минимальные smoke-checks (без ломки архитектуры), либо описать отсутствие тестов как риск

5. **Аудит “что не проходит и почему”**

   * классификация проблем: ENV / Selenium / Selector / Network / Cloudflare / State-machine / Config / Paths / OS-specific
   * для каждой проблемы: **симптом → причина → фиксация → риск → как проверить**

6. **Готовый отчёт в Markdown**

   * положить в `docs/AUDIT_V0_4_2.md`
   * приложить логи и скриншоты (пути, имена файлов)

7. **Подготовка к GitHub**

   * проверить `.gitignore` (venv, logs/screenshots при необходимости)
   * оформить коммит: “Audit v0.4.2 + run gate”
   * убедиться, что проект запускается с README шагами

### Ограничения

* Cloudflare/капча **не обходить**. Только детект/ожидание/ручной шаг.
* Не менять структуру проекта без необходимости.
* Патчи делать минимальные, объяснять каждую правку.

  * `pip freeze | head`

Если хочешь без лишних циклов — просто пришли сюда `tree` + `requirements.txt` + текущий лог ошибки (если будет).
